# 无人机检修与电池安装

旋翼拆除且驱动断电的无人机教学台。 当前配置为 [scene.json](../scene.json)，初始输入使用其中的 `initial_instruction`。

## 任务与打断

1. BAT：插入，接收对象 BAY。
2. GUARD：旋转，角度 -30 度。
3. M3：结构检查。

常驻目标：VOLTMETER。

临时检查输入：暂时检查 M3 的内侧减震垫，之后恢复原任务。

检查完成后恢复原任务，核对 task_id、动作参数、接收对象和原步骤顺序。动画终点保持等待确认；明确完成后才更新实体位姿。同一对象出现多个动作时，分别保留步骤。

## 对象与结构

| 对象 | 名称 | 动作能力 | 结构与观察说明 |
|---|---|---|---|
| BAT | 训练电池 | point、insert | 底部具有两条导轨，装入开口朝上的电池仓。 |
| BAY | 电池仓 | point | 开口朝上，底部止挡面和金属触点可见。 |
| GUARD | 护罩锁扣 | point、rotate | 电池护罩侧面的独立旋转锁扣，顺时针角度为负。 |
| M1 | 前左电机 | point | 具体尺寸、位姿和观察方向见场景配置。 |
| M2 | 前右电机 | point | 具体尺寸、位姿和观察方向见场景配置。 |
| M3 | 后左电机 | point、inspect_back | 电机内侧减震垫位于局部 +X 面，检查视图朝该表面。 |
| M4 | 后右电机 | point | 具体尺寸、位姿和观察方向见场景配置。 |
| VOLTMETER | 台式显示仪 | point、wait | 显示训练电路状态，数值来自仿真状态。 |

尺寸、位姿、转轴、接合坐标系与检查面以配置为共同来源。资产使用标准 glTF 坐标，运行时使用米制、Z 轴向上的世界坐标。工作区域取景涵盖任务对象，结构检查对准模型中的实际部件。

## 构建和验收

统一资产构建入口为 `scripts/scenes/build_simulation_assets.py`，原生构建入口为 `scripts/scenes/build_all.sh`。生成的 Blender 文件位于本场景目录的 `scene.blend`。调整资产时核对已有有效细节、材质、纹理与许可来源。

按照 [验证标准](../../../docs/VALIDATION.md) 完成自动、几何、真实模型、Viser 和 Blender 检查。原生图像与视频覆盖工作区域、操作特写、检查面、起点、动作过程、终点等待、临时检查与恢复；Viser 同时检查宽屏与较窄窗口。最终报告关联实际代码摘要与证据。历史提案、评审和运行记录保留其原始证据含义，当前版本的完成状态由本次验收记录确定。
