## 次要建议

1. **QRC 行沿视轴距离与其自身表值不自洽(约 1cm)**:按所给相机与世界位复算,QRC/VALVE 行为 1.10m 而非 ≈1.11m;且"相邻层差 0.45 / 0.71m"中的 0.45 既不等于其自身表值之差(1.57−1.11=0.46),也不等于复算值(≈0.47–0.48)。分层结论(≥0.3m)不受影响,但 v2 声称"按 |(P−C)·d̂| 重算自洽"在近端行只近似成立,建议把该行改为 ≈1.10m、层差改为 ≈0.47/0.71m。
2. **"逐个"对比只点名 4/9 个场景**:对比段覆盖 drone_bench、server_rack、shelf_picking、optical_bench,未显式对比 v1 三件套、dig_site 与 engine_bay;其中 engine_bay 与本场景能力三元组相同({insert, rotate, inspect_back}),最值得一句显式区分(经本审查独立对比,结构仍可区分,不构成 major)。
3. **对 drone_bench 的区分论据略单薄**:其远层同为"读数监控",提案对"全程持续 vs 事件触发"的论证只对 server_rack/shelf_picking/optical_bench 展开,对 drone_bench 仅靠序结构与竖向布局区分;建议补一句两者远端读数语义的差别(或承认相近、以序结构为准)。
4. **GAUGES 打包了"压力表组与压缩机控制箱"**:压缩机本体是布景,控制箱并入 GAUGES 合法但角色略含混(监控/暂停动作是否涉及控制箱);建议在 description 中说清控制箱在 wait/pause 语义中的地位。
