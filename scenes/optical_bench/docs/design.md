## 场景七 `optical_bench` 光具座同轴校准(替代 watch_service)

**世界**:光学实验室 1.2m 面包板:近端激光器出口,二号柱位待插透镜,中段折转反射镜,远端靶屏。调镜的手在近中段,判同轴的眼睛必须看远端光斑——**跨层注意是任务内禀需求**,不是并发装饰。与论文的光学主题自洽。

**视点与深度**:`camera_position_m=[0.5,-0.85,0.55]`,`camera_look_at_m=[0,0.55,0.12]`。
| 层 | 对象 | 位置(y,z) | 沿视轴距离 | role / depth | N/σ 倾向 |
|---|---|---|---|---|---|
| 近 | L1→POST2 透镜插入 | y≈+0.15, z≈0.10 | ≈1.1m | current / precise | 高 N,小 σ |
| 中 | M 反射镜旋转+背面 | y≈+0.55, z≈0.12 | ≈1.5m | next / persistent | 中 N,大 σ |
| 远 | TARGET 靶屏光斑 | y≈+1.25, z≈0.15 | ≈2.2m | background / persistent | 低 N,大 σ |
| 布景 | 面包板、激光器、L2、线缆 | — | — | 环境层(部分交互) |

**任务脚本**:
- 初始指令:`把透镜 L1 插进二号柱位 POST2,再把反射镜 M 顺时针转 15 度把光斑引向靶屏,全程盯着 TARGET 上光斑的位置,最后看 M 背面的镀膜编号。`
- 打断:`先看 M 的镀膜编号,光路的事保留。`
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 把那个透镜挪一下 | L1/L2 均在清单 → clarify |
| 再转一点 | 缺角度 → clarify |
| 光斑偏了,再顺时针 5 度 | 参数化 rotate 更新,角度显式 -5 |
| 把靶屏转过来 | TARGET 无 rotate → 校验拒绝 |
| 把 L1 插深些 | 锚点终点唯一 → interrupt 按既有 POST2 锚点演示 |
| 模型服务断开时发指令 | 界面可见错误,动作冻结 |

**为什么强契合**:光路同轴判断要"穿过多个元件看远端光斑",平面屏幕上三维光路坍缩为 2D 投影,无法用高亮等价;手(近层插透镜/调镜)与眼(远层判光斑)的调焦距离差 1.1m,是结构性跨层任务。L1/L2 真歧义、顺时针 15°(fixture 记 -15)角度参数、"全程盯着"持续性要求由 LLM 解析。M 背面镀膜编号为径向面,转台式查看成立。

**交互对象**:
| id | label | capabilities | anchors | description |
|---|---|---|---|---|
| L1 | 一号透镜 | point, insert | — | 凸透镜带镜架,插柱式 |
| POST2 | 二号柱位 | point | insertion=[0,0,0.03](pose 世界位 [0,0.15,0.10]) | 面包板定位孔柱 |
| L2 | 二号透镜 | point | — | 已装调好的另一枚透镜(消歧用) |
| M | 折转反射镜 | point, rotate, inspect_back | — | 背面有镀膜编号,白线为入射基准 |
| TARGET | 靶屏 | point, wait | — | 屏上光斑位置即同轴判据 |

**环境**:面包板(程序化孔阵 + `metal_plate` 纹理)、激光器外壳、挡光幕、`desk_lamp_arm_01`、`screwdrivers_02`、`magnifying_glass_01`、`binder_notebook`、`rough_linen`/`marble_01` 纹理。`render_hints`:ortho_scale≈0.85,grid_extent≈1.6,cue_scale=0.5,label_offset=0.06。
