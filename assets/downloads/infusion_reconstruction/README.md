## Geometry, materials and interface adaptations

`scripts/scenes/rebuild_infusion_assets.py` builds the six original task objects and environment. It does not modify `scenes/infusion_ward/scene.json`. Standard GLB Y-up is converted to Z-up once on loading; all scale factors below are uniform. Source file units and source bounds are used for a teaching layout, not as manufacturer measurements or an assertion of OEM compatibility between these unrelated models.

- **PUMPCASSETTE / SLOT2:** the Contec model contains 15,871 source triangles and no image textures. `Object_10` component 0 is the case; component 1 is the door. These and the source latch/controls/handle are scaled by 0.46. The case is opened by an exact Boolean cut; the door is attached to an explicitly authored carrier. The handle moves 20 mm toward the fixed control half, clear of the teaching insertion channel. ABS/metal colors are scalar PBR assignments. The original complete pump is not presented as a clinical interchangeable cassette.
- The carrier has four 1.20 mm-radius guiding pins at local `(x,z)=(±.012,±.030)` m. The receiver has four genuine 1.65 mm-radius through bores in the rear guide plate, nominal radial clearance 0.45 mm. The source already forms the left cavity wall: added left extensions occur only outside its vertical extent, with no overlapping middle wall. The unchanged cassette goal is `[.05,.198,1.30]` m; its real bottom is local `z=-.0475`, bearing on the receiver's actual bottom rail at world `z=1.2525`. Initial support is the cart work lid at world `z=.950`.
- **BAG1 / BAG2:** only the mature `WaterBag_All_Tools_0` mesh is used (552 triangles). Uniform scale 0.36646792525809857, 4.5° Y rotation then −90° Z rotation, centering and a −10 mm Z offset preserve its folds and UVs. The original alpha-bearing film map remains, with nonmetallic material, roughness .50 and double-sided BLEND. A small removable reinforced seal clip adds a real 4.5 mm-radius hanging eye because the source lacks a modeled perforation. The fixed support sleeve has 4.48 mm radius and a 20 µm nominal gap to that inner eye. The new opaque, surface-following +Y labels read **TRAINING A / TRAINING B**, **SIMULATION ONLY**, and the bag ID; the original task inspection point is preserved. Their 61×55 mm footprint is cut directly from the actual outer sheet triangles and offset 60 µm toward +Y, preserving every source fold boundary instead of bridging across it. Existing printed clinical markings remain source texture, not instructions supplied by this project.
- **MONITOR:** select the monitor-head components from `monitor_monitor_0`, rotate −90° around Z, scale uniformly by .018 and center. Source screen/base-color/normal/metallic-roughness maps are retained. The displayed trace and values are a static source texture, not patient data or a simulated physiological result. A small rear mounting adapter and teaching label connect it to the stand without changing its task pose.
- **Cart and stand:** the cart scale is `.940/(82.64271545410156-1.5466232299804656)`, placing its true highest tray rim at .940 m. A removable 620×480×10 mm work lid has top .950 m, supported by four 12×12 mm feet whose underside vertices are projected onto the source rim. This is finite, distributed geometric contact, not a claim that every interpolated underside location conforms to the rim. The stand is uniformly scaled to 1.91 m; its pole is centered at XY `[.025,.56]`. Four source wheel components are translated vertically onto the floor without deformation. Supplementary hanger crossbar, hooks, sleeves and device mounting arms adapt the fixed task positions. Source cart textures are retained; the stand receives scalar metal/rubber PBR materials.
- **STOPCOCK:** this one small core component is project-authored teaching geometry. No suitable freely redistributable medical rotor model was obtained; an unrelated Y splitter or industrial valve was not substituted. A transparent fixed three-port body and separate blue handle/spindle preserve the original −Y axis and −90° interaction. The 5.5 mm-radius spindle sits in a 5.65 mm-radius bore; the actual handle shoulder and fixed annular face meet at local `y=-.004`. The three 2.4 mm-radius port channels are open geometry. Arrow decals rotate with the handle. This models a visual teaching control, not fluid routing, sterility, a clinical workflow or a certified medical device.
- **Reference only for STOPCOCK:** [Welford Medical 3-way stopcock](https://www.welfordmedical.com/product/3-way-stopcock/) and [m|devices IV110000 product sheet](https://www.mdevices.com.au/uploaded/PDSs/IV110000%20PDS.pdf%20-%203-Way%20Stopcock1.3.pdf). These informed the transparent body, three-port shape and flow arrows. No manufacturer CAD, image or text is incorporated, and no license is claimed for those reference pages.
- The floor reuses the project's existing CC0 Poly Haven `marble_01` material. Its provenance remains in the existing shared asset records; it is not one of the five CC BY models above.

## Reproducing the receiver case

`contec_receiver_case.glb` is the only precomputed geometry derivative. It retains Nataliatorres777's attribution and CC BY 4.0 terms. `prepare_receiver_case.py` contains both necessary steps, so reconstruction does not depend on a transient work directory. Extraction verifies the original file SHA256, selects `Object_10` connected component 0, converts Y-up to Z-up, subtracts `[.03723799902945757,0,.03684599883854389]`, applies uniform .46 scale and the documented Y translation. Blender then subtracts a cube with local bounds `[-.0205,-.042,-.050]` to `[.0205,.016,.050]`, using the EXACT Boolean solver, and exports standard Y-up GLB.

From the repository root, with a designated process directory and its temporary/cache environment already configured:

```sh
.venv-simulation/bin/python -B assets/downloads/infusion_reconstruction/prepare_receiver_case.py extract --work .work/two_scene_rebuild/infusion
/home/hdd3/zhanghaonan/opt/blender/blender -b --factory-startup -t 4 --python assets/downloads/infusion_reconstruction/prepare_receiver_case.py -- cut --work .work/two_scene_rebuild/infusion
```

The batch uses the project resource guard/job wrapper around these commands (4 CPU threads, 12 GiB RSS, no GPU). The second command deliberately updates only the derived receiver GLB; the five original downloads remain unchanged. Blender 3.1.2 was used for the recorded derivative. To validate reproduction without replacing it, add `--output .work/two_scene_rebuild/infusion/receiver_case_reproduced.glb` to the second command. Final task meshes are produced by the normal scene builder, not by this preparation script.

Native Blender source and candidate views were actually inspected. Author geometry checks use the exported candidate triangle surfaces, including carrier support, bag-eye/sleeve contact, fixed rear mounts and stopcock shoulder. These finite checks do not establish continuous collision freedom, dynamics or clinical function; the main reconstruction pipeline independently checks the unchanged task paths and both renderers.
