# 提案 `dive_fillstation`:潜水气瓶充装前核验与接通(v2)

充装员在潜水俱乐部充装间给 3 号气瓶接通充气路:近端低位把充装软管快插接头接上瓶阀出口,核对瓶肩的检验钢印(充装前强制核验),确认无误后开启汇流排阀杆,远端壁挂压力表组全程盯压。**差异化标记**:**安全规程内禀的全程持续监控**(充装安全规程要求充装期间专人盯压,GAUGES 是规程红线对象——区别于任务伴生型远端监控;optical_bench 的靶屏同为内禀任务对象,但它是单次判据目标,本场景远端对象承载的是**全程持续性**监控要求)+ **inspect_back 对象与消歧组同体**(BOTTLE3 既是插入参照又是钢印核对目标,三只同型瓶构成消歧组)。

与现有场景的结构对比(逐个):drone_bench 双 precise 为近端连续两步;本场景两个 precise 步(近端低位快插、中端阀杆开度)中间隔 persistent 钢印核对步,且近端对象在低位(瓶站位)、远端在壁挂高位,纵深斜跨地面到墙面。server_rack / shelf_picking / optical_bench 的远端监控对象分别为状态灯、到位指示、光斑判据;本场景远端对象是**定量工艺参数表**(指针读数,"别超压"为数值红线),监控语义为全程持续而非事件触发。

## 修订记录(v1 → v2)

round1 审查结果:research **pass**、feasibility **pass**(5 条次要问题);realism **fail**(major)——v1 把年检钢印虚构到汇流排接头背面,真实规程中气瓶检验标记在**瓶肩**且须**充装前**核对,该 inspect_back 核心步骤无行业实践支撑。v2 修正:① inspect_back 目标改为 BOTTLE3 瓶肩检验钢印(充装前核验,真实规程),核对时序移到开阀之前;② 插入动作由「装阀入瓶口」改为「充装软管快插接头 QRC 接瓶阀出口」(瓶阀出厂/检验后随瓶,充装员日常接的是软管接头,工艺链:软管→瓶阀→瓶体,自洽);③ v1 feasibility 的次要问题一并修正:坐标按 |(P−C)·d̂| 重算自洽、锚点改瓶阀出口局部原点、差异化措辞修正(不再声称现有远端监控均为伴生,如实承认 optical_bench 靶屏同为内禀但机制不同)。

## 世界

潜水俱乐部气瓶充装间。近处地面充装位并排站立三只同规格黄色潜水气瓶(BOTTLE1/2/3,检验钢印均打在**瓶肩**环带、仅编号不同,瓶口均已装好瓶阀),3 号位瓶阀(VALVE)出口朝向充装员,汇流排垂下的 3 号路固定充装软管末端是待接快插接头(QRC);中段墙面装六路汇流排,每路有阀杆,3 号路阀杆(STEM)垂直向下为关闭;远端墙挂压力表组与压缩机控制箱(GAUGES),表组指示各路缸压、带红色超压区。角落空气压缩机为布景。纵深布局由充装工艺决定:接管在近端低位,开阀在中段墙面,而「充装全程专人盯压、不得超压」是气瓶充装安全规程的强制要求——近端手上操作与远端读数监控在同一次充装里并存。

## 视点与深度

`camera_position_m=[0.30,-1.05,1.30]`,`camera_look_at_m=[0.05,0.60,1.00]`(设计初值)。沿视轴距离按 |(P−C)·d̂| 计算,下表与所给世界位坐标自洽(建模定稿后以实测为准)。

| 层 | 对象 | 世界位概要(设计初值) | 沿视轴距离 | task_role / depth_requirement | N/σ 倾向 |
|---|---|---|---|---|---|
| 近(低位) | QRC→VALVE 快插接头接瓶阀出口 | [0.25,-0.05,0.63] | ≈1.11m | current / precise | 高 N,小 σ |
| 近(步骤,非独立层) | BOTTLE3 瓶肩检验钢印核对 | [0.25,-0.05,0.50] | ≈1.12m | next / persistent | 中 N,大 σ |
| 中 | STEM 3 号路阀杆逆时针 90° 开启 | [0.30,0.55,1.20] | ≈1.57m | next / precise | 中高 N,小 σ |
| 远 | GAUGES 压力表组 | [0.10,1.30,1.50] | ≈2.28m | background / persistent | 低 N,大 σ |

沿视轴调焦距离 1.11 / 1.57 / 2.28m,相邻层差 0.45 / 0.71m(≥0.3m);depth_requirement 覆盖 precise 与 persistent 两档。

## 任务脚本

- 初始指令:`把充装软管接头 QRC 接到 3 号气瓶瓶阀 VALVE 的出口上,接好后核对 BOTTLE3 瓶肩的检验钢印在不在有效期内,确认无误再把汇流排 3 号路阀杆 STEM 逆时针开 90 度,压力表组 GAUGES 全程盯着别超压。`
- 打断:`先别开阀,1 号瓶 BOTTLE1 的钢印也一起核一下,3 号瓶的事保留。` → interrupt:BOTTLE1 抢占为 current(inspect_back),接通队列挂起;`核完了,继续开 3 号路阀杆。` → resume。
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 先把那个瓶子接上 | BOTTLE1/2/3 同型在清单 → 指代不明,clarify |
| 把阀杆拧一下 | 有 rotate 缺角度 → clarify,不编造 0 度 |
| 接头再插紧一点 | 锚点终点唯一 → interrupt 按既有 VALVE 出口锚点演示,不改终点 |
| 把压力表翻过来看 | GAUGES 无 inspect_back → 校验拒绝 |
| 把 BOTTLE3 转过来看肩部钢印 | BOTTLE3 无 rotate → 校验拒绝(钢印核对走 inspect_back ghost 演示) |
| 表压升太快先停一下 | pause 语义,状态保存 |
| 连续快速发两条指令 | epoch 竞争,仅最新 epoch 可提交 |

## 环境

汇流排管路与支架、空气压缩机钣金、充装位固定链、墙面与地面 PBR(程序化建模为主;气瓶为圆柱+球肩标准件,压力表为圆盘+指针贴图)。

## 为什么强契合

1. **焦深分层必要性**:接管(1.11m)低头对准低位瓶阀出口、开阀杆(1.57m)抬到中段墙面、盯压(2.28m)始终看着远端表组——"手上接管、眼睛盯表"由充装安全规程强制,三档调焦距离并存是任务内禀的;平面屏幕+HUD 无法同时保留「出口对准」与「表组读数」的独立焦面。全息收益现阶段为仿真演示假设。
2. **遮挡与背面信息**:3 号瓶的检验钢印打在瓶肩背向充装员一侧(瓶子固定在充装位,不能整体旋转);半透明 ghost 副本绕瓶轴(竖直局部 Z)转 180°(转台式)露出钢印面——钢印位于瓶肩侧壁环带,面法线水平 ⟂ 局部 Z,属径向面,符合建模约定。
3. **LLM 解析必要性**:"3 号气瓶/3 号路"编号指代、BOTTLE1/2/3 同型消歧、"逆时针 90 度"显式角度(fixture 记 +90)、"全程盯着别超压"持续性、开阀前核对打断-恢复;缺角度与指代不明必须 clarify。
4. **空间锚定动作**:QRC 插入终点由 VALVE 出口局部坐标 insertion 锚点唯一决定;"再插紧一点"按既有锚点 interrupt 演示,不改终点;ghost_motion 演示结束不等于操作完成。
