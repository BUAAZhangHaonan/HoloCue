# 提案 `dive_fillstation`:潜水气瓶充装与年检核对(v1)

充装员在潜水俱乐部充装间给气瓶装阀并接通充气路:近端把瓶阀拧入瓶口,中端开启汇流排阀杆、核对充装接头背面的年检钢印,远端壁挂压力表组全程盯压。**差异化标记**:**安全规程内禀的持续监控**("充装全程盯压"是气瓶充装安全规程的强制要求,不是装饰性并发)+ **旋入类锚定插入**(螺纹装配,区别于现有场景的导轨/卡扣插入)。现有场景的远端监控(rack 告警灯、drone 电压表、optical 靶屏)均为任务伴生监控,本场景的远端对象是安全规程的直接对象;插入方式亦未出现过。

## 世界

潜水俱乐部气瓶充装间。近处充装台上并排放三只同规格黄色潜水气瓶(BOTTLE1/2/3,仅肩部钢印编号不同),台面立着待装瓶阀(VALVE,黄铜手轮);中段墙面装六路汇流排,每路有快插接头与阀杆,3 号路接头(CHECKVALVE)背面刻上次检测钢印,3 号路阀杆(STEM)垂直向下为关闭;远端墙挂压力表组与压缩机控制箱(GAUGES),表组指示各路缸压。角落空气压缩机为布景。纵深布局由充装工艺决定:装阀在台面近端,开阀与核钢印在汇流排中段,盯压必须始终看着远端表组——"手上装阀、眼睛盯表"是充装规程的内禀要求。

## 视点与深度

`camera_position_m=[0.85,-1.30,1.35]`,`camera_look_at_m=[-0.10,0.45,1.05]`(设计初值)。

| 层 | 对象 | 位置概要 | 沿视轴距离 | task_role / depth_requirement | N/σ 倾向 |
|---|---|---|---|---|---|
| 近 | VALVE→BOTTLE3 瓶阀装入瓶口 | 充装台台面,z≈1.0 | ≈1.0m | current / precise | 高 N,小 σ |
| 中 | STEM 3 号路阀杆逆时针 90° 开启 | 汇流排面,z≈1.2 | ≈1.5m | next / precise | 中高 N,小 σ |
| 中 | CHECKVALVE 接头背面年检钢印 | 汇流排 3 号路,z≈1.2 | ≈1.5m | next / persistent | 中 N,大 σ |
| 远 | GAUGES 压力表组 | 远端墙面,z≈1.5 | ≈2.2m | background / persistent | 低 N,大 σ |

沿视轴调焦距离 1.0 / 1.5 / 2.2m,相邻差 0.5/0.7m;depth_requirement 覆盖 precise 与 persistent 两档。

## 任务脚本

- 初始指令:`把瓶阀 VALVE 装到 3 号气瓶 BOTTLE3 的瓶口上,再把汇流排 3 号路阀杆 STEM 逆时针开 90 度,核对一下 3 号路接头 CHECKVALVE 背面的年检钢印,压力表组 GAUGES 全程盯着别超压。`
- 打断:`先停下,3 号路接头有漏气声,先查接头背面,装阀的事保留。` → interrupt:CHECKVALVE 抢占为 current(inspect_back),装阀队列挂起;`看完了,继续装阀。` → resume。
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 先把那个瓶子接上 | BOTTLE1/2/3 同型在清单 → 指代不明,clarify |
| 把阀杆拧一下 | 有 rotate 缺角度 → clarify,不编造 0 度 |
| 阀再拧紧一点 | 锚点终点唯一 → interrupt 按既有 BOTTLE3 锚点演示,不改终点 |
| 把压力表翻过来看 | GAUGES 无 inspect_back → 校验拒绝 |
| 把 BOTTLE3 转过来看肩部编号 | BOTTLE3 无 rotate → 校验拒绝(编号核对用 label 指认) |
| 表压升太快先停一下 | pause 语义,状态保存 |
| 连续快速发两条指令 | epoch 竞争,仅最新 epoch 可提交 |

## 环境

汇流排管路与支架、空气压缩机钣金、充装台、气瓶固定链、墙面与地面 PBR(程序化建模为主;气瓶为圆柱+球肩标准件,压力表为圆盘+指针贴图)。

## 为什么强契合

1. **焦深分层必要性**:装阀(1.0m)对准瓶口、开阀与核对钢印(1.5m)移到汇流排面、盯压(2.2m)始终看着远端表组——"手上装阀、眼睛盯表"由充装安全规程强制,三档调焦距离并存是任务内禀的;平面屏幕+HUD 无法同时保留"瓶口对准"与"表组读数"的独立焦面。全息收益现阶段为仿真演示假设。
2. **遮挡与背面信息**:年检钢印刻在接头背面(朝墙一侧),正面只能看到快插口;半透明 ghost 副本绕局部 Z 转 180°(转台式)露出钢印面——接头体侧面为径向面,符合建模约定。
3. **LLM 解析必要性**:"3 号气瓶/3 号路"编号指代、BOTTLE1/2/3 同型消歧、"逆时针 90 度"显式角度(fixture 记 +90)、"全程盯着别超压"持续性、漏气打断-恢复;缺角度与指代不明必须 clarify。
4. **空间锚定动作**:VALVE 旋入终点由 BOTTLE3 局部坐标 insertion 锚点唯一决定(旋入式锚定);"再拧紧一点"按既有锚点 interrupt 演示,不改终点;ghost_motion 演示结束不等于操作完成。
