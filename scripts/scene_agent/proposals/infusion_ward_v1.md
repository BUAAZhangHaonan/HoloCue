# 提案 `infusion_ward`:病房输液泵装管与床头监护(v1)

护士在普通病房床旁完成一次输液泵装管:近端把泵盒插入泵槽、拧开三通,中段核对高处挂袋背面的配置标签,远端床头监护仪全程盯数值。**差异化标记**:报警驱动的「抢占→恢复」闭环(background 监护仪因报警事件抢占为 current,处理完再恢复装管队列)+ 输液架垂直纵深(医疗护理域)。现有场景中 server_rack 的告警灯只是被动背景,engine_bay/drone_bench 的打断由用户口语发起;本场景的事件源为脚本时间线报警,构成"设备事件抢占-恢复"的结构,未被任何现有场景覆盖。

## 世界

医院普通病房单床单元。病床靠墙,床侧立输液架:架上部挂两袋同规格糖水(BAG1 已挂 5%GS、BAG2 备用 10%GS,配置标签均贴在**袋背面**),架中部挂单通道输液泵,泵正面 2 号泵槽(SLOT2)空置、槽口朝向护士;泵下管路串有三通旋塞(STOPCOCK,手柄横向为关闭)。床旁治疗车顶层放着全新一次性泵盒(管路预装)。床头墙面挂多参数监护仪(心率/血氧,报警时黄色闪烁)。护士站位:治疗车—输液架—床头近似成一线,视线沿视轴从近端泵槽一直延伸到床头屏幕。站位与纵深由护理操作规程决定:装管必须面对泵槽,而监护要求护士在操作期间持续留意床头读数——近操作与远监控在同一步流程里并存。

## 视点与深度

`camera_position_m=[0.55,-1.25,1.42]`,`camera_look_at_m=[-0.15,0.40,1.22]`(设计初值)。

| 层 | 对象 | 位置概要 | 沿视轴距离 | task_role / depth_requirement | N/σ 倾向 |
|---|---|---|---|---|---|
| 近 | PUMPCASSETTE→SLOT2 泵盒插入 | 治疗车→泵槽,z≈1.15 | ≈1.0m | current / precise | 高 N,小 σ |
| 中近 | STOPCOCK 三通顺时针 90° 开启 | 泵下管路,z≈0.95 | ≈1.1m | next / precise | 中高 N,小 σ |
| 中 | BAG1 糖袋背面配置标签 | 架上部,z≈1.75 | ≈1.6m | next / persistent | 中 N,大 σ |
| 远 | MONITOR 床头监护仪 | 床头墙面,z≈1.55 | ≈2.2m | background / persistent | 低 N,大 σ |

沿视轴调焦距离 1.0 / 1.6 / 2.2m,相邻差 0.6m(≥0.3m);depth_requirement 覆盖 precise 与 persistent 两档。

## 任务脚本

- 初始指令:`把新泵盒 PUMPCASSETTE 插进输液泵的 2 号泵槽 SLOT2,插好后把三通 STOPCOCK 顺时针拧 90 度打开,再核对一下 BAG1 背面的配置标签是不是 5% 糖,床头监护仪 MONITOR 全程盯着。`
- 打断:`先停下,监护仪血氧报警了,先看 MONITOR,泵的事保留。` → interrupt:MONITOR 抢占为 current(wait),装管队列挂起;`报警处理完了,继续装泵。` → resume。(报警事件源为确定性脚本时间线,非感知网络。)
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 把那袋糖翻过来看下标签 | BAG1/BAG2 同型在清单 → 指代不明,clarify |
| 把三通拧一下 | 有 rotate 缺角度 → clarify,不编造 0 度 |
| 把泵盒再插深一点 | 锚点终点唯一 → interrupt 按既有 SLOT2 锚点演示,不改终点 |
| 把 MONITOR 转过来 | MONITOR 无 rotate → 校验拒绝 |
| 把糖袋转 30 度 | BAG1 无 rotate → 校验拒绝 |
| 血氧又响了先看监护 | 事件驱动 interrupt,epoch 竞争下仅最新可提交 |
| 连续快速发两条指令 | epoch 竞争,仅最新 epoch 可提交 |

## 交互对象(锚点为参照对象局部坐标)

| id | label | capabilities | anchors | description |
|---|---|---|---|---|
| PUMPCASSETTE | 一次性泵盒 | point, insert | — | 管路预装的输液泵盒,卡入泵槽 |
| SLOT2 | 2 号泵槽 | point | insertion=[0,0,0](设计初值;世界位约 [-0.05,0.12,1.18],槽体中心即满插终点) | 泵正面导轨槽,槽口朝护士 |
| STOPCOCK | 三通旋塞 | point, rotate | — | 手柄横向为关,顺时针 90° 全开 |
| BAG1 | 5% 糖袋 | point, inspect_back | — | 背面贴配置标签(袋体贴面为径向面) |
| BAG2 | 10% 糖袋 | point | — | 消歧用,同型备用袋 |
| MONITOR | 床头监护仪 | point, wait | — | 心率/血氧数值,报警时黄色闪烁 |

## 环境

病床与床头柜、输液架底座与挂钩、治疗车、病房墙地(常规 PBR)、隔帘、呼叫按钮(程序化建模为主;管路与袋体半透明材质程序化生成)。

## 为什么强契合

1. **焦深分层必要性**:装管(1.0m)对准泵槽、核对标签(1.6m)抬头看挂袋、监护(2.2m)再抬眼到床头屏——三档调焦距离是护理流程本身要求的顺序切换;平面屏幕+角落 HUD 无法同时保留"泵槽对准"与"床头读数"两个焦面,注意资源会被 HUD 挤占。全息收益现阶段为仿真演示假设,由后续对照实验测定。
2. **遮挡与背面信息**:配置标签贴在袋背面,袋体朝护士一面只能看到药液;半透明 ghost 副本绕局部 Z 转 180°(转台式)展示标签面,袋体贴面为径向面,符合建模约定。
3. **LLM 解析必要性**:指令含"2 号泵槽"编号指代、BAG1/BAG2 同型消歧、"顺时针 90 度"显式角度(fixture 记 -90)、"全程盯着"持续性、报警打断-恢复;缺角度与指代不明输入必须 clarify。
4. **空间锚定动作**:PUMPCASSETTE 插入终点由 SLOT2 局部坐标 insertion 锚点唯一决定;"再插深一点"按既有锚点 interrupt 演示,不编造新终点,演示结束不等于操作完成。
