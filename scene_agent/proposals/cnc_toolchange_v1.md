# 提案 `cnc_toolchange`:立式加工中心刀库补刀(v1)

数控操作工在安全门开启的立式加工中心前手动补刀:近端把刀柄插入当前朝向操作工的刀套,中端盘车让刀库转过一角度、再查另一把刀柄尾部被刀套遮挡的拉钉,远端立柱控制面板全程盯报警。**差异化标记**:**旋转与插入目标的耦合结构**——刀库盘 rotate(盘车 60°)改变后续 inspect_back 目标(T03)的可达位置,旋转是检查步骤的使能步;现有 9 场景中没有任何"旋转改变另一对象可达性"的任务图(制造域)。

## 世界

车间立式加工中心,安全门开启。操作工站在门开口处:手边刀臂托盘上是带拉钉的 BT40 粗镗刀柄 T09;机身右侧挂 12 工位圆盘刀库,当前 9 号刀套(POCKET9)朝向开口、可直接插刀,盘上另有一把同规格粗镗刀柄 T03 插在 3 号刀套(POCKET3)里,其柄尾拉钉被刀套侧壁遮挡;刀库盘(MAG)可手动盘车绕水平轴转位。立柱上数控控制面板(PANEL)显示程序状态与报警灯。纵深布局由机床结构决定:刀套插拔在近端开口、刀库盘面在中段、控制面板在立柱远端——操作工补刀时按规程必须同时留意面板报警状态。

## 视点与深度

`camera_position_m=[1.35,-1.55,1.50]`,`camera_look_at_m=[-0.20,0.15,1.05]`(设计初值)。

| 层 | 对象 | 位置概要 | 沿视轴距离 | task_role / depth_requirement | N/σ 倾向 |
|---|---|---|---|---|---|
| 近 | T09→POCKET9 刀柄插入 | 刀库开口刀套,z≈1.15 | ≈0.95m | current / precise | 高 N,小 σ |
| 中 | MAG 刀库盘顺时针 60° 盘车 | 盘面中心,z≈1.20 | ≈1.45m | next / precise | 中高 N,小 σ |
| 中 | T03 柄尾拉钉(被刀套遮挡) | POCKET3 内,z≈1.20 | ≈1.45m | next / persistent | 中 N,大 σ |
| 远 | PANEL 控制面板 | 立柱侧面,z≈1.45 | ≈2.05m | background / persistent | 低 N,大 σ |

沿视轴调焦距离 0.95 / 1.45 / 2.05m,相邻差 0.5/0.6m;depth_requirement 覆盖 precise 与 persistent 两档。

## 任务脚本

- 初始指令:`把镗刀 T09 插进刀库现在的 9 号刀套 POCKET9,然后把刀库盘 MAG 顺时针盘 60 度让 3 号位过来,检查 T03 柄尾拉钉背面有没有松动,控制面板 PANEL 全程盯着报警。`
- 打断:`刀库先停,面板报警灯亮了,先看 PANEL,补刀的事保留。` → interrupt:PANEL 抢占为 current(wait),刀库队列挂起;`报警看完了,继续补刀。` → resume。
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 把那把镗刀插好 | T03/T09 同规格均在清单 → 指代不明,clarify |
| 把刀库盘转一下 | 有 rotate 缺角度 → clarify |
| T09 再插深一点 | 锚点终点唯一 → interrupt 按既有 POCKET9 锚点演示 |
| 把面板转过来 | PANEL 无 rotate → 校验拒绝 |
| 把 T03 转半圈看看松不松 | T03 无 rotate(拉钉检查用 inspect_back)→ 校验拒绝 |
| 报警灯亮了先看面板 | 事件驱动 interrupt;epoch 竞争仅最新可提交 |
| 连续快速发两条指令 | epoch 竞争,仅最新 epoch 可提交 |

## 交互对象(锚点为参照对象局部坐标)

| id | label | capabilities | anchors | description |
|---|---|---|---|---|
| T09 | 9 号镗刀柄 | point, insert | — | BT40 柄+拉钉,待入库 |
| POCKET9 | 9 号刀套 | point | insertion=[0,0,0](设计初值;世界位约 [0.38,0.40,1.15],套孔中轴即满插终点) | 当前朝向开口的空刀套 |

| POCKET3 | 3 号刀套 | point | — | 盘车 60° 后朝向开口 |

## 环境

机床钣金机身与安全门、主轴头、工作台与夹具、排屑槽、车间地面与墙、刀具托盘(程序化建模为主;刀柄为圆柱+锥面标准件,刀套沿圆盘阵列)。

## 为什么强契合

1. **焦深分层必要性**:插刀(0.95m)对准刀套孔、盘车与查拉钉(1.45m)移到盘面、盯报警(2.05m)再移到立柱面板——三档调焦距离由机床结构决定,补刀流程天然在三者间切换;平面屏幕+HUD 无法在"对准套孔"的同时保留远端报警状态的独立焦面。全息收益现阶段为仿真演示假设。
2. **遮挡与背面信息**:T03 柄尾拉钉位于刀套内侧、被套壁遮挡;半透明 ghost 副本绕局部 Z 转 180°(转台式)露出拉钉端面——拉钉端面为绕刀柄轴线的径向面,符合建模约定。
3. **LLM 解析必要性**:"9 号刀套"编号指代、T03/T09 同规格消歧、"顺时针 60 度"显式角度(fixture 记 -60)、"全程盯着"持续性、报警打断-恢复;缺角度与指代不明必须 clarify。
4. **空间锚定动作**:T09 插入终点由 POCKET9 局部坐标 insertion 锚点唯一决定;"再插深一点"按既有锚点 interrupt 演示,不改终点;ghost_motion 演示结束不等于操作完成。
