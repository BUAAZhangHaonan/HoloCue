# 提案 `cnc_toolchange`:立式加工中心手动装刀与拉钉点检(v2)

数控操作工在安全门开启的立式加工中心前手动补刀:先把立柱面板上的模式旋钮切到手动档(远端精确旋转),再把镗刀插入当前朝向自己的刀套(近端精插),然后拔出另一把同规格刀柄翻看柄尾被遮挡的拉钉(中段查背面),控制面板报警灯全程监控(远端)。**差异化标记**:**链首远层 precise rotate**(模式切换是手动装刀的安全前置,旋转使能的是作业模式而非对象位置)+ **远端同距双角色**(current 操作对象 MODESWITCH 与 background 监控对象 PANEL 同在最远层)——现有 9 场景的 rotate 全部位于近/中端,且无「远起近收」的链结构。

与现有场景的结构对比(逐个):drone_bench 双 precise 为「近端连续两步」;本场景双 precise 分处远端(2.10m 旋钮)与近端(1.06m 插刀),中间隔查背面。optical_bench 的 rotate 是近端参数化迭代更新;本场景角度为一次性模式切换,无参数化迭代。shelf_picking 的同深度对照为 current/next 同在中层;本场景同距对照为 current/background 且同在最远层。

## 修订记录(v1 → v2)

round1 审查(major):① realism——手动盘车 60° 与隔着刀套目视查拉钉不符合 CNC 行业习惯(常规为面板电控转位、拉钉用扭矩扳手复紧),而该段是 v1 的承重结构;② feasibility——12 工位刀库 9 号套在开口时,盘 60°(移 2 工位)不可能让相隔 6 工位(180°)的 3 号套到位,v1 差异化核心算术不成立;且深度表与相机坐标实算矛盾。v2 修正:删除手动盘车结构,改为真实流程「模式旋钮切手动档(v1 遗漏的强制前置)→ 插刀入当前开口刀套 → 拔刀手持翻看点检拉钉」;拉钉点检改在**拔出后手持状态**下进行(行业常规点检方式,松动目视可辨);刀库盘保留为 point-only 对象,「转一下」成为能力负例(电控转位,不手动盘车);几何按 |(P−C)·d̂| 重算自洽。

## 世界

车间立式加工中心,安全门开启。操作工站在门开口处:立柱侧面的数控面板上,模式选择旋钮(MODESWITCH,当前指向「自动」档)与报警灯、程序状态屏同在面板(PANEL);机身右侧挂 12 工位圆盘刀库,**电控转位**、当前 9 号刀套(POCKET9)朝向开口、可直接手动插刀;刀臂托盘上是带拉钉的 BT40 粗镗刀柄 T09(待入库);盘上 3 号刀套(POCKET3)里插着同规格粗镗刀柄 T03,其柄尾拉钉被刀套侧壁遮挡,需拔出后手持翻看。纵深由机床结构与安全规程决定:切手动档必须先在远端面板完成,插拔刀在近端开口,而补刀期间按规程要求留意面板报警状态——远端精确操作与远端持续监控同在最远层,近端精插在中途。

## 视点与深度

`camera_position_m=[1.05,-0.95,1.45]`,`camera_look_at_m=[0.00,0.45,1.15]`(设计初值)。沿视轴距离按 |(P−C)·d̂| 计算,下表与所给世界位坐标自洽(建模定稿后以实测为准)。

| 层 | 对象 | 世界位概要(设计初值) | 沿视轴距离 | task_role / depth_requirement | N/σ 倾向 |
|---|---|---|---|---|---|
| 远 | MODESWITCH 顺时针 90° 切手动档 | [0.10,1.00,1.45] | ≈2.10m | current / precise | 高 N,小 σ |
| 近 | T09→POCKET9 刀柄插入 | [0.72,0.08,1.12] | ≈1.06m | next / precise | 中高 N,小 σ |
| 中 | T03 拔出翻看柄尾拉钉 | [0.35,0.38,1.20] | ≈1.51m | next / persistent | 中 N,大 σ |
| 远 | PANEL 控制面板(报警灯) | [0.10,1.02,1.45] | ≈2.10m | background / persistent | 低 N,大 σ |

沿视轴调焦距离 1.06 / 1.51 / 2.10m,相邻差 0.45 / 0.59m(≥0.3m);depth_requirement 覆盖 precise 与 persistent 两档;MODESWITCH 与 PANEL 同处 ≈2.10m 远层、一 current 一 background。

## 任务脚本

- 初始指令:`先把模式旋钮 MODESWITCH 顺时针拧 90 度切到手动档,把镗刀 T09 插进刀库当前的 9 号刀套 POCKET9,再把 3 号刀套里的 T03 拔出来,翻看柄尾的拉钉有没有松动,控制面板 PANEL 全程盯着报警灯。`
- 打断:`T03 先别拔,报警灯亮了,先盯着 PANEL 看是什么报警,拔刀的事保留。` → interrupt:PANEL 提升为 current(wait),拔刀队列挂起;`报警看完了,继续拔 T03。` → resume。
- 扩展测试输入:

| 输入 | 检查点 |
|---|---|
| 把那把镗刀插好 | T03/T09 同规格均在清单 → 指代不明,clarify |
| 把模式旋钮拧一下 | 有 rotate 缺角度 → clarify,不编造 0 度 |
| T09 再插深一点 | 锚点终点唯一 → interrupt 按既有 POCKET9 锚点演示,不改终点 |
| 把刀库盘 MAG 转一下 | MAG 仅 point(电控转位,不手动盘车)→ 校验拒绝 |
| 把面板转过来 | PANEL 无 rotate → 校验拒绝 |
| 报警灯亮了先停一下 | 事件语义(报警为脚本时间线),pause/抢占 |
| 连续快速发两条指令 | epoch 竞争,仅最新 epoch 可提交 |

## 环境

机床钣金机身与安全门、主轴头、工作台与夹具、排屑槽、车间地面与墙、刀具托盘(程序化建模为主;刀柄为圆柱+锥面标准件,刀套沿圆盘阵列)。

## 为什么强契合

1. **焦深分层必要性**:切档(2.10m)在远端面板、插刀(1.06m)回到近端开口、查拉钉(1.51m)在中段手持、盯报警(2.10m)始终在远端——「远起近收」的调焦切换由安全规程(先切手动)与机床结构(开口/面板位置)共同决定;平面屏幕+HUD 无法同时保留「套孔对准」与「面板报警状态」的独立焦面。全息收益现阶段为仿真演示假设。
2. **遮挡与背面信息**:T03 柄尾拉钉在刀套内被侧壁遮挡;拔出后仍需翻转刀柄才能看到柄尾——半透明 ghost 副本绕局部 Z 转 180°(转台式)露出拉钉端面,拉钉端面为绕刀柄轴线的径向面,符合建模约定。
3. **LLM 解析必要性**:「9 号/3 号刀套」编号指代、T03/T09 同规格消歧、「顺时针 90 度」显式角度(fixture 记 -90)、「全程盯着」持续性、报警打断-恢复;缺角度与指代不明必须 clarify。
4. **空间锚定动作**:T09 插入终点由 POCKET9 局部坐标 insertion 锚点唯一决定;「再插深一点」按既有锚点 interrupt 演示,不改终点;ghost_motion 演示结束不等于操作完成。
