# 场景提案审查依据(三轮审查共用)

本文件是所有审查的唯一判据来源,提炼自 `AGENTS.md`(研究定义、工程约束)、`docs/09_新场景与任务设计.md`(四判据)与用户 2026-09-17 的真实性要求。

## 1. 研究定义边界(违反即 fail)

- 主线:**任务驱动的全息焦深提示**。LLM 输出任务角色、优先级、深度需求、对象与动作;Gaussian 数量 N 与显示配置由确定性模块独立映射(N←priority,σ 档位←depth_requirement);σ 为相对示意参数。
- 提案不得:引入资源调度网络、把 Gaussian 数量变成 LLM 自由输出、把示意模糊写成物理实验、发明研究定义之外的新机制或新交互范式。
- 全息收益在现阶段是**仿真演示假设**,提案措辞不得写成已验证的物理结论。

## 2. 四条设计判据(docs/09,每条都必须满足)

1. **焦深分层必要性**:任务天然包含 ≥3 个**沿主视轴方向调焦距离差 ≥0.3m** 的关注对象,depth_requirement 覆盖 ≥2 档(precise/persistent/neutral);显式声明 `camera_position_m`/`camera_look_at_m`,深度表给出沿视轴近似调焦距离。若一块平面屏幕加高亮/角落 HUD 就能等价完成,不合格。
2. **遮挡与背面信息**:存在 inspect_back 步骤;被查看的信息面必须是**径向面**(绕局部 Z 转动能转到朝向相机),不得是纯顶/底面。
3. **LLM 解析必要性**:自然语言多步任务,含指代消解(混淆项必须是交互对象、会进入 LLM 清单)、颜色/位置属性、显式角度参数、打断-恢复语义;欠参数输入触发 clarify 而非编造;锚点类动作"再往里一点"按既有锚点 interrupt 演示,不改终点、不编新终点。
4. **空间锚定动作**:≥1 步 insert/assemble,终点由参照对象局部坐标锚点唯一决定;ghost_motion 演示;演示结束≠操作完成。

## 3. 真实性判据(2026-09-17 用户要求,本轮新增)

- 场景必须是**真实世界常见职业的日常工作**(每天或每周高频发生),不是罕见行业、影视化场景或虚构设定。
- **拒绝猎奇**:`dig_site` 考古探方已被判定"过于猎奇"——罕见行业、新奇但非典型的路线一律不接受;新提案不得再走这类路线。
- 深度/注意力冲突(近端操作 + 远端监控)必须是任务**内禀**的(行业规程、工艺或安全要求),不是为制造纵深而摆拍的布局。
- 对象命名、指令措辞应符合该行业的真实口语与规程用语。

## 4. 工程现实

- capabilities 合法值:`point` / `rotate` / `inspect_back` / `insert` / `assemble` / `wait`;task_role:`current` / `next` / `background`;depth_requirement:`precise` / `persistent` / `neutral`。
- 交互对象 **5–8 个**(含消歧项),ID 为 ASCII;能力负例(要求无该能力的对象执行该动作→校验拒绝)至少 2 条。
- 坐标约定:米制、Z 向上、右手系;rotate 绕对象局部 Z 逆时针为正,顺时针输入在 fixture 中记负角;锚点写在**参照对象局部坐标系**。
- 环境对象仅渲染,不进 LLM 清单;资产以程序化建模 + CC0 素材(PolyHaven/ambientCG)为路线,工作量与现有 v2 场景同量级。
- 提案阶段数值(相机/距离/锚点)为**设计初值**:审查只查量级与结构合理性,不要求建模精度;建模定稿后以 `configs/scenes/<id>.json` 实测为准。

## 5. 现有场景与任务图标记(差异化基准)

| 场景 | 域 | 任务图标记 |
|---|---|---|
| blocks / connector / control_panel(v1) | 桌面教具 | 接口闭环验证 |
| server_rack | 数据中心运维 | 单 precise 精插 + 深处查背面 + 远层告警监控 |
| drone_bench | 无人机检修 | 双 precise 连续步 + 遮挡查背面 + 远层读数监控 |
| shelf_picking | 仓储分拣 | 双 background 监控 + 同深度不同角色对照 |
| optical_bench | 光学实验室 | 跨层内禀注意(手近眼远)+ 参数化角度更新 |
| dig_site | 田野考古 | 非插入类 current + neutral 档(**判定猎奇,待替换**) |
| engine_bay | 汽车维修 | rotate + insert + inspect_back 复刻验收 |

新提案必须给出**差异化标记**,并与上表所有任务图结构不重合(域不同不等于结构不同,反之亦然)。
