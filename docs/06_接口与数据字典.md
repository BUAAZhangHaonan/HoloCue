# 接口与数据字典

## 语义计划

`Decision` 提供 operation、assistant_message、cues。operation 为 replace、interrupt、resume、complete、pause 或 clarify。新计划包含一条 current，随后为 next，最后可有 background。字段见 `schemas/semantic_decision.schema.json`。

每条 cue 指定 target_id、action、cue_type、task_role、priority、depth_requirement、instruction，以及动作必要的 angle_deg 或 reference_id。priority 为 0 到 5。depth_requirement 为 precise、persistent、neutral。模型输出额外的 N、sigma 或实体坐标会被拒绝。

## 持久状态

SQLite 是当前任务的权威状态，包含 queue、suspended、completed、history、revision 与 epoch。LangGraph 负责解释与场景校验，持久状态由服务事务控制。resume 恢复队列内原 Task，保留 task_id 和参数。当前设计每个目标同时只有一条提示，一个场景一个操作会话。

revision 标识对外状态版本，客户端修改请求带 expected_revision。epoch 标识规划尝试，后来的尝试使早先结果失效。request_id 与输入指纹提供幂等提交；相同 ID 携带不同内容须拒绝。

## 显示包

`DisplayPacket` 提供 schema_version、session_id、scene_id、revision、epoch、execution、renderer_kind、units、axes、calibration_id、budget_total 和 cues。全局单位为米、右手系 Z 向上、旋转 wxyz。

每条 DisplayCue 提供 n_gaussians、sigma_value、sigma_units、sigma_profile、pose、goal_pose 以及语义参数。阶段一 renderer_kind 恒为 semantic_preview。测得参数进入配置后，当前网页仍属于语义预览；真实光学执行由后续独立适配器确认。

相对 σ 的 1、2.5、4 仅用于当前 UI 示例。待合作者提供标定，映射模块加载版本化曲线；不得给相对值补上米单位冒充标定。

## 已实现的 HTTP 入口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /health | 服务和模型路径类型 |
| GET | /api/v1/scenes | 可用场景 |
| POST | /api/v1/sessions | 创建场景会话 |
| GET | /api/v1/sessions/{id} | 权威状态 |
| POST | /api/v1/sessions/{id}/messages | 异步语义更新，返回 job |
| GET | /api/v1/jobs/{id} | 规划状态与原始记录 |
| GET | /api/v1/sessions/{id}/display | 当前显示包 |
| GET | /api/v1/sessions/{id}/events | 事件日志 |
| POST | /api/v1/sessions/{id}/control/{operation} | 显式暂停、恢复、完成 |

默认 API 8750、Viser 8780、本地模型 8000，绑定 127.0.0.1。生产式内网调用需要配置 HOLOCUE_API_KEY、认证客户端、明确访问策略，并对图像和日志设置保存规则。

## 后续光学适配器

协议预留 capabilities、submit、cancel。建议由光学端返回支持的 primitive、预算上限、合法 σ 范围、标定版本、坐标变换和状态确认。提交确认至少包含 accepted_revision、accepted_epoch、loaded_frame_id、时间戳和错误信息；真实呈现延迟由双方统一时钟或往返测量界定。

Gaussian NPZ 的 positions 目前是对象局部几何采样，provenance 明确为未做光学拟合。后续可增加幅值、相位、二维尺度与局部基向量，扩展需提升格式版本。镜头、相位编码、载频和 SLM 控制由合作者维护，Agent API 不假定具体设备。

## 运行证据与隐私

模型 job 保存原始请求与响应，包括失败时的 HTTP 正文。可选图像会保存在请求证据中。runs 默认不进入 Git，涉及真实人员或私密内容时先明确授权、保存周期和分享范围，再开展采集。共享演示证据前移除 API 密钥与私密数据。
