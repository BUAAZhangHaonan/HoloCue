# 接口与数据字典

当前 HTTP 路径、请求字段和桥接方式统一见 [接口说明](API.md)。数据结构以 `src/holocue/models.py` 中的 Pydantic 模型为准，场景与显示机制见 [系统架构](SIMULATION_ARCHITECTURE.md)。

## 语义、任务与显示

模型提交对象、动作、任务角色、优先级和深度需求，以及角度或接收对象等必要动作参数。模型输出通过严格数据结构和场景能力校验；预算、实体坐标与 Gaussian 响应由确定性模块计算。

持久任务状态保存有序队列、挂起任务、完成记录和版本。同一对象可拥有多个独立有序步骤；恢复使用原任务身份。revision 表示状态版本，epoch 使过期规划失效，request_id 用于请求幂等。每个浏览器连接使用独立会话。

DisplayPacket 保存会话、场景、版本、执行状态、显示预算和提示。运行时位置以米表示，坐标为右手系、Z 轴向上，姿态四元数顺序为 wxyz。场景资产自身采用标准 glTF 坐标，由资产模块统一转换。

解析响应参数及来源保存在 `configs/preview_response.json`。当前三维响应使用 `analytic_gaussian_preview` 标识，其宽度与强度计算不能作为真实光学标定结果。后续光学模块通过 `HolographyAdapter` 的 capabilities、submit 和 cancel 接口接入。

## 证据

模型调用保存实际请求、原始回复和错误。Viser 与 Blender 桥接帧保存相机、对象位姿、任务时间、提示中心、半径、颜色、不透明度与版本。最终验收引用本次代码和实际记录；密钥不进入代码、截图或公开报告。
