# 十二个场景的任务与建模约定

场景用于任务可行性评价与 Agent 调试。机械动作由显式几何约束定义，所有器材按教学装置或受控实验环境呈现。每个场景都包含临时检查和恢复原任务的验收路径。

| 场景 | 完整任务 | 几何结构与观察重点 |
|---|---|---|
| control_panel | B 逆时针旋转 30 度，检查 C 背面 | 旋钮轴、方向标记和面板固定；C 的背面具有定位键、接触端子和标签。检查视点面向这些真实结构。 |
| connector | P 插入 S，检查 C 背面 | 插头和插座采用四针与顶部定位键；插座具有实际开口、孔位和容纳空间。终点依据接合位置计算。 |
| blocks | A 放到底板，检查 B 底部 | 积木具有上表面凸点、底部空腔和支撑管；底板采用规则间距。检查视点从底部观察。 |
| server_rack | SPARE 装入 SLOT4，检查 NODE3，保留告警 | 固定机架、导轨和承接位置保持一致。NODE3 在检修支架上展示后方端口。 |
| drone_bench | BAT 装入 BAY，旋转 GUARD，检查 M3，保留仪表 | 电池仓具有空腔、导轨和止挡面；电机保留真实壳体和内侧减震垫。教学状态使用拆除旋翼的机体。 |
| shelf_picking | RED 放进 BASKET，检查 BLUE 标签 | 移动路径先从货架正面退出，再通过空闲区域搬运。货架、托盘和筐体使用实际边界。 |
| optical_bench | L1 安装到 POST2，旋转 M，再检查 M | 镜架支杆和柱座共用轴线。M 的两条连续任务完整保存；检查面显示镀膜标识。 |
| dig_site | 指认与检查记录对象，放置 FLAG | 工作区具有探方、土层、标记点和测量仪。FLAG 的终点位于目标旁边，保留文物空间。 |
| engine_bay | CLAMP 螺钉旋转，PLUG 进入 PLUGPORT，检查 CONN | 固定卡箍带与旋转螺钉分别建模。火花塞井口保持中空，连接器放在可观察支座上。 |
| cnc_toolchange | 模式旋钮旋转，T09 装入 POCKET9，检查 T03 | 教学刀套提供法兰承接面，刀架、控制面板与刀库示教盘组成隔离服务工位。拉钉使用斜向近景展示颈部与端部。 |
| dive_fillstation | 检查 BOTTLE3 标识，接合 QRC，转动 STEM，保留仪表 | 气瓶、阀体、手轮和接口分别表达；工作站处于卸压教学状态。标签面和螺纹接合方向明确。 |
| infusion_ward | 泵盒装入 SLOT2，检查 BAG1，旋转 STOPCOCK，保留监视器 | 训练泵盒具有导向柱和槽体空腔；旋塞固定体与手柄分开。训练袋用于标识检查。 |

每个 JSON 中的 `initial_instruction`、`ordered_steps` 和 `interrupt_instruction` 给出实际执行输入与验收目标。执行者需要核对模型产出的目标、动作、接收对象、角度和顺序。

积木采用 LDraw 开底砖体，教学尺度下侧壁厚 3.2 毫米、管柱壁厚 1.6 毫米，保留凸点与开放底腔。积木、连接器和无人机工作台共用 30 毫米支撑基准，工作垫、嵌垫和网格线具有互不重叠的实体空间。电池起点嵌垫按实际导轨与接触片开槽；装入终点使用电池导轨底面和电池仓内底面作为接触坐标，两者局部高度均为 -25.5 毫米。

服务器节点在机架前方完成横向对齐，再沿导轨装入；SPARE 的接近距离为 0.80 米。货筐放置面位于局部高度 -85 毫米，与真实内底板上表面一致。充气训练阀体复用源模型的实际螺纹接收腔，接头按原接合坐标进入；教学接头的 8 毫米贯通孔、外壁与接收腔净空分别从实际导出表面检查。

CNC 工作区域仍从左前方观察。控制面板与刀库示教盘通过实际后部安装面连接支架，模式旋钮与固定轴座分离。T09 起点由源法兰下表面在世界 Z=1.085 米处承托，装入 POCKET9 后同一表面落在 Z=1.240 米处；铣刀末端保留自由空间。工具的起点、刀套接合位置、旋转角度和任务顺序保持原约定。

CAD 网格导出清理圆角极点产生的零面积三角面，并验证拓扑。有效圆角、边界、材质和细节保留；资产视觉检查仍使用实际原生图像。

实体网格使用 trimesh 的邻接连通平滑组：相邻面夹角小于 20 度时连通，组间拆分顶点以保留硬边。20 度是分组参数；连续圆角、椭球或凹槽中的两个面可能经其他面连通，因此局部夹角超过 20 度仍可平滑。圆柱端盖与侧壁等实际硬边由不同组分离，曲面内部使用连续法线。glTF 显式导出 `NORMAL`，使 Viser 与 Blender 读取同一套法线；这一处理不移动顶点或改变有效三角面。标签保留原有 UV 与纹理图像，不因法线处理丢失文字映射。法线、硬边与材质的最终效果仍需对应的实际原生图像验收。

## 视觉验收

每个场景保存工作区域、正面、操作特写和结构检查图。原生 Viser 验收同时使用宽屏和较窄窗口，当前任务的信息应当能够直接阅读。旋转操作的特写沿实际转轴观察指示线和角度，结构检查呈现描述中指定的端子、底面、标签或减震垫。

完整视频必须覆盖动作起点、接近过程、终点保持、显式完成、临时检查和恢复。检查方向标记是否与旋转一致，源对象是否经过真实开口，实体位姿是否在确认后更新，提示是否仍然位于对应对象附近。

资产精细度审核检查硬边与圆角、空腔厚度、支撑关系、接插件孔位、文字纹理、材质反射和比例关系。保留现有资产中有效的细节，并依据统一几何契约调整位置和局部结构。所有最终通过结论均关联实际原生图像。

## 素材重构的分批约定

2026-10-22 起，每批最多重构两个场景。货架拣选、服务器维护、光学平台与考古探方已完成。2026-10-23 第三批接续控制面板与连接器，并按用户补充要求仅替换考古测站和三脚架；其余九个场景目录保持第三批开始时的内容。后续组合根据前一批的真实导出和观察结果再调整，不一次改完剩余场景。本轮工作是资产重构，不运行端到端实验。

前一批已确认的做法：

- 先复用已取得且许可明确的模型与 PBR 材质，再核对米制单位、轴向和零件比例。共享池为 Z-up，最终场景 GLB 为标准 Y-up；场景内材质适配应操作副本。
- 支撑位置以导出网格的实际底面为准。服务器外包络比真实承托底板宽，纸箱扫描底面也可能不平；AABB 相交或接近不等于实际接触。
- 在最终 Blender 和 Viser 中分别看材质。无透明通道的塑料筐误设 BLEND/单面会丢失整片实体壁；这个修复只适用于实际不透明材料，不能照搬到玻璃。
- 可操作对象、旋转轴、接合点、检查点与任务顺序保持独立。增加装饰、接口和线缆后再核对提示面和装配空间。
- 扫描件的说明必须与其真实可见特征一致。不得为匹配旧程序模型的描述而伪造文物刻纹或设备结构；必要文案修正应保留原检查功能并写明原因。
- 本批验收限于实际导出资产、必要局部几何检查和真实原生视图。复用相机进行前后对比；不把静态检查写成任务端到端成功率或动力学验证。

光学平台与考古探方这一批新增的做法：先检查 CAD 文件内的独立实体，不按文件名直接叠放。Winters/Shepler 的 C13 与 C14 下载文件虽然哈希不同，却包含同一组实体，本场景只采用一次。CAD 在原始毫米单位下细分后再转米，避免单位转换造成无谓的高面数。带图节点变换的 GLB 应先烘焙到项目坐标，再根据实际顶点生成米制 UV。

摄影测量件按比例统一缩放，尺度未知的扫描不推定为实物原尺寸。先在原生 Blender 查看正反面，确定检查点所面对的真实表面，再适配土面或软垫支承；不整平陶片、添加虚构刻纹或把教学复制件描述成同一遗址出土组合。细长工具还需核对实际支承姿态，包络内可用尺寸受厚度约束时在记录中说明。

真实画面复看还修正了三类问题：防滑锈钢板纹理不适合精密光学孔板，板面改用平整金属 PBR；直接把扫描下表面向下挤出会形成柱状“土支承”，改为与坑底同一网格的平缓土床；透射玻璃不再叠加低 alpha，且 Blender 3.1 原生构建从光学 GLB 恢复旧导入器遗漏的 Transmission 与 IOR。后续透明资产必须同时检查 GLB 属性、原生材质节点及两端实际画面。扫描的内外表面可能分属多个 primitive，壁厚检查应覆盖完整扫描；薄卡片承托则从真实相交面采样，不能只依赖稀疏的整体三角形采样。

第三批的结构边界：控制面板的 A/B 使用成熟旋钮和电位器 CAD，旋转轴和轴套随对象转动，固定刻度、承座及电位器定子属于环境。白色指示线需落在完整旋钮顶面，不能横跨源模型的径向开槽。C 保留原检查点，黄色定位键延伸到真实检查面，后方四个端子保持可见。

连接器使用同一份 Adafruit 铝型材盒 CAD 构成 P/S/C 外壳；P/S 的四针、贯通孔、绝缘载体与顶键属于教学接口适配。原外包络、位置、姿态、接合坐标、动作和任务定义不变；内部针距按成熟壳体与实际四孔匹配，不拉伸原 CAD 横截面。真实孔腔、轴向容纳长度和顶键槽需从导出三角面核对；产品来源不能据此延伸为厂家认证的四针接插件。原始 STEP 只存一份，两场景共享引用。

考古测站采用带原始贴图的全站仪模型与独立 Artec 三脚架扫描，分别等比适配。三个真实足端接触土沿，仪体底部三点接触转接盘；只对足端邻域土面调平，其他六个考古对象资产保持原内容。没有纹理的扫描应如实说明，不能用额外材质赋值冒充原始摄影测量材质。三脚架原有扫描器 U 架按连接处拆除，避免与全站仪叠放成不合理双头结构。

第三批原生预览发现，工具源模型的长轴可能竖直；若先按高度上限缩放，会把完整螺丝刀缩成竖立的小针。应先整体烘焙图节点并刚体调整为真实放置姿态，再等比适配并检查承托。带线缆的立式仪表则需观察整个源模型，不能为了统一轴向把仪表和卷线一起放倒。已有橡胶地砖纹理也不自动适合工作台垫；优先依据用途判断材料，而非仅以“已有 PBR”作为选用理由。上述问题须在正式构建前完成原生画面复看，几何检查通过不代替这一环节。

支承检查还必须覆盖装配终点。连接器 P 的起点与插入终点相差 4 毫米高度，起点落桌不代表插到底后也有承托。保留原接合坐标，以两条固定承托在终点接触 P 的真实底脚，并在最终导出后检查两脚接触、承托落垫以及完整静态插入路径。不要把插针与孔之间的装配净空误当作承重接触。

第四批仅接续 `blocks` 与 `drone_bench`，沿用不运行端到端实验的边界；其他十个场景目录保持批次开始时的内容。两份场景 JSON 逐字节保留。积木采用 LDraw 原始凸点、底腔和管柱，16 毫米间距由 0.8 毫米/LDU 的等比转换取得；只把直壁从 19.2 毫米延至原合同的 20 毫米。凸点保留独立的 3.2 毫米高度，不能为了包进砖身标注尺寸而压扁。BASE 保留源圆角和凸点截面，裁减外圈为 14×10 点阵。

成熟源模型的开放表面不能按“非闭合即忽略”处理。LDraw 的管柱与凸点是开放连接 primitive，木桌、书本等亦可能不是闭体；真实三角面仍需纳入路径与承托检查，不为通过闭体测试封住原检查空腔。闭合实体才使用体内外判断。几何验证按有限姿态采样，并明确容差，不把检查通过称为连续碰撞证明。

无人机机架移除源高脚起落架并等比对齐四个原电机中心；电机独立适配，不扭曲碳纤维管截面。电池长线按完整连通部件移除，包体单独等比放入成熟下壳，避免整件外包围盒拟合把主体缩成小道具。BAY 的开口、止挡和支承是按原交互接口设计的教学适配件。BAT 起点导轨最低处是 28 毫米，桌垫顶面是 30 毫米，需实际凹槽；最终两条导轨落在 BAY 的真实止挡面，不能只检查起点。GUARD 的旋转检查需纳入已装入 BAT 的姿态。M3 的检查点位于橙色圈中心孔，真实橙色表面可见性应沿环带多方向取样，不能要求中心射线命中橙色。

GUARD 仍是原合同内的教学旋转操纵件，使用成熟旋钮与独立固定轴座；本批没有补造可动护罩、锁舌传动或实际电池机械锁紧功能。保留顺时针 30 度交互与确认流程，不把这一静态模型称为已验证的实体电池锁扣。该边界与未运行动力学、端到端任务实验的范围分别记录。

第四批真实双端画面还暴露了材质辨识问题：Viser 中三个管柱的底环各 96 个三角面和朝向均正确，近裁切面为 2 毫米；同色、同法线的环口和内顶面在无阴影照明下视觉融合。修复限于本场景同色系的较深内表面材质，不翻转正确绕序、不增加双面设置、不修改全局灯光，也不把它称为源 PBR 纹理或真实 AO。M3 减震圈同样在实际两端检查后提高橙色色彩辨识。电池导轨之外的两片接点比垫顶低 1 毫米，另加真实接点凹槽；只给导轨开槽会留下隐蔽穿透。

第五批仅接续 `engine_bay` 与 `cnc_toolchange`。保留两份 JSON 全部原字节和其余十个场景，沿用原生 Blender、真实 Viser 与同相机对比，不运行端到端实验。

发动机采用完整三缸源模型和独立服务件，原位置通过检修支架适配。火花塞原接合坐标不等于网格最低点，支承由源金属肩面决定；开放承座须留出螺纹和电极空间，不能简单挤出整个肩面而侵入螺纹。油盖也必须在真实下表面承托。固定卡箍带与成熟螺钉分开，旋转保持原教学动作，没有新增螺纹进给或软管夹紧动力学。胶管不能沿用通用管线函数的金属材质；材质判断应核对实际导入节点和原生画面。

CNC 源文件的动画状态需要在 Blender 内核对：vincent.leung 的原文件第 1 帧为装配态，静态直接读取可能得到分解图。烘焙后保留铣刀、开槽筒夹和锁紧螺母；源 HSK 本体不用于 BT 外形。Toolrack 的 V 槽与驱动缺口法兰等比复用，外锥与拉钉明确标注为教学适配。刀套以法兰接触面承托，不能让刀尖落底。分件模型的材质、原轴向和轮子朝向均需实看，不能只从 GLB 格式推断作者使用了标准轴向。

接收套内外件需要实际接触拼接。重叠的井口顶环或埋在未开孔实体内的螺钉不能只靠渲染遮掩，应在最终导出三角面上检查。连接器检查须覆盖所有真实端子口，拉钉须同时覆盖颈部和端帽；多点检查比仅让中心射线命中模型更接近用户实际观察。所有这些几何检查仍是有限姿态和采样点下的静态证据。

实际接触既要位置匹配，也要表面朝向相对。源法兰的负体积和反向绕序须在复用时修正；不能靠双面材质掩盖错误法线。大三角面对应小支承片时，单侧固定重心网格可能漏掉真实支承，应从两侧实际三角面取样并验证射线命中，仍要求接触点分散、两面法线对置及原距离容差，以悬空和同向法线反例确认没有放宽条件。已精确焊接且闭合的细面网格也不能反复做退化面清理，否则可能删除有效薄面并把闭体变成开口。

第六批仅接续 `dive_fillstation` 与 `infusion_ward`，至此十二个场景完成分批素材重构。两份 JSON 保留全部原字节，其他十个场景目录保持批次开始时内容；验证限于实际保存的 Blender 场景、真实 Viser 视图和必要局部几何检查，不运行端到端任务或语言模型。

复用模型前应在 Blender 查看独立部件及源材质。静态 Y 分流器不能当作可转三通旋塞；没有适用且许可明确的源模型时，少量接口适配几何应单独说明。通用球阀的固定阀体和旋转手柄分别归属环境与操作对象，旋转检查须包含已经插入的 QRC；输液旋塞同样分离固定透明体与活动手柄，并在已装入泵盒的场景中检查净空。
