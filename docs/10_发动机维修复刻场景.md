# 场景 09：发动机舱维修（engine_bay）

复刻目标：参考照片为 AR 辅助发动机维修——横置直列四缸发动机（大众 EA888/EA211 风格）装在开启引擎盖的机舱内，AR 面板显示 "C1394 UNSCREW AND REMOVE"（第 3/7 步），技师持螺丝刀拆进气软管卡箍，周围有 C3297/C4816/C4163/C5761 标注点。本场景复刻机舱+发动机+车库工位，不建人物，任务主线对齐"任务驱动的全息焦深提示"。

## 设计判据核对（沿用 docs/09 四判据）

1. **视轴 ≥3 层、层间调焦距离差 ≥0.3m**：相机自机舱前左上方俯入。五层：卡箍 CLAMP ≈1.47m → 火花塞/机油盖 ≈1.70m → 火花塞孔 ≈1.84m → 张紧轮 ≈1.95m → 变速箱侧连接器 ≈2.30m。全程 0.83m 调焦跨度（相邻两层最小差 0.12m：PLUGPORT→TENSIONER），其中"近层→远层"三档差 ≥0.3m 满足（1.47 / 1.84 / 2.30 两两差 0.37m、0.46m）。
2. **深度需求 ≥2 档**：rotate/insert 任务要求 precise（近、精对准），inspect_back 要求 persistent（远、持续观察）。
3. **LLM 必要性**：指令含顺序（先…接着…最后）、角度（逆时针 90 度）、指代（把 PLUG 插进 PLUGPORT）、可打断改序（先看 CONN 背面）。
4. **锚点**：PLUGPORT.insertion（火花塞孔口）、（备用）OILCAP 旋转演示。TENSIONER 释放张紧为 rotate。

## 任务指令（逐字符进 configs/scenes/engine_bay.json）

- 初始：`把 CLAMP 逆时针转 90 度，接着把 PLUG 插进 PLUGPORT，最后检查 CONN 的背面。`
- 扩展测试输入（E2E 用）：
  - 打断：`先别管卡箍，直接看 CONN 的背面。`（interrupt→suspended）
  - 恢复：`继续刚才 CLAMP 的任务。`（resume）
  - 角度改参：`CLAMP 改成顺时针转 45 度。`（replace，旧动作停止）
  - 能力违规：`把 PLUG 旋转 720 度。`（PLUG 无 rotate 能力 → DomainError 留痕）
  - 顺序澄清：`先检查 CONN，再装火花塞，卡箍最后。`
